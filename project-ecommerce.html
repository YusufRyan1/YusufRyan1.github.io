Pipeline Design

End-to-End Process

01
Python — Fact Table
Engineered Revenue Fact Table with strict business rules: cancelled orders excluded, invalid quantities removed, 100% accuracy enforced.
02
PostgreSQL — Load
Loaded cleaned dataset into PostgreSQL. SQL reconciliation queries validated row counts and revenue totals against source.
03
DAX — Measures
Built DAX measures for AOV, Promo Revenue %, B2B vs B2C split, and fulfillment breakdowns with dynamic filtering.
04
Power BI — Dashboard
6+ interactive visuals enabling drill-down by promotion, fulfillment type, category, and monthly trend.
