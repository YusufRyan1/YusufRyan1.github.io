System Design

High Level Architecture

The warehouse follows Medallion Architecture — CRM and ERP CSV sources flow through Bronze (raw), Silver (cleansed), and Gold (business-ready) layers, consumed by BI tools, ad-hoc SQL, and ML models.

Sources → Bronze → Silver → Gold → Consume (BI & Reporting · Ad-Hoc SQL · Machine Learning) Architecture

Data Model

Star Schema — Sales Data Mart

The Gold layer star schema with fact_sales at the centre connected to dim_customers and dim_products. Sales are calculated as quantity × price, with full date, shipping, and due date tracking.

Key Queries

Analytics SQL

Customer Lifetime Value
-- CLV: total revenue per customer WITH customer_sales AS ( SELECT c.customer_key, c.first_name, c.last_name, SUM(f.sales_amount) AS total_revenue, COUNT(f.order_number) AS total_orders, MIN(f.order_date) AS first_order, MAX(f.order_date) AS last_order FROM gold.fact_sales f JOIN gold.dim_customers c ON f.customer_key = c.customer_key GROUP BY c.customer_key, c.first_name, c.last_name ) SELECT *, DATEDIFF(MONTH,first_order,last_order) AS tenure_months FROM customer_sales ORDER BY total_revenue DESC;
Month-over-Month Growth
-- MoM revenue growth with LAG() WITH monthly AS ( SELECT YEAR(f.order_date) AS yr, MONTH(f.order_date) AS mo, SUM(f.sales_amount) AS revenue FROM gold.fact_sales f GROUP BY YEAR(f.order_date), MONTH(f.order_date) ) SELECT *, LAG(revenue) OVER( ORDER BY yr, mo) AS prev, ROUND((revenue - LAG(revenue) OVER( ORDER BY yr,mo)) * 100.0 / NULLIF( LAG(revenue) OVER( ORDER BY yr,mo),0 ),2) AS mom_pct FROM monthly ORDER BY yr, mo;
Silver — Deduplication
-- Remove duplicates with ROW_NUMBER() WITH deduped AS ( SELECT *, ROW_NUMBER() OVER( PARTITION BY cst_id, cst_key ORDER BY cst_create_date DESC ) AS rn FROM bronze.crm_cust_info WHERE cst_id IS NOT NULL ) INSERT INTO silver.crm_cust_info SELECT cst_id, cst_key, cst_firstname, cst_lastname, cst_marital_status, cst_gndr, cst_create_date FROM deduped WHERE rn = 1;
Product Performance Ranking
-- Products ranked by revenue in category SELECT p.category, p.product_name, SUM(f.sales_amount) AS revenue, SUM(f.quantity) AS units_sold, RANK() OVER( PARTITION BY p.category ORDER BY SUM(f.sales_amount) DESC ) AS rank_in_cat, ROUND( SUM(f.sales_amount)*100.0 / SUM(SUM(f.sales_amount)) OVER(),2 ) AS revenue_share_pct FROM gold.fact_sales f JOIN gold.dim_products p ON f.product_key=p.product_key GROUP BY p.category,p.product_name ORDER BY revenue DESC;
